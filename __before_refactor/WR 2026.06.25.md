# Performance Comparison: Eager (Ha) vs Eager (Prof.) vs Normal Infer

## Common

+ Base model: `hgnetv2_b5.ssld_stage2_ft_in1k-20260224-76-98.66.pth`
+ Parameter tunes on `val-video-set`
+ Perf test on `test-video-set`
+ Note that inference results of model can be modified before performing any further processes related to `Eager` mode:
  + `NormalInferProc` : Keep the inference results as they are (no changed)
  + `ProfInferProc` : using `reliable_th` (see
    `src/methods/skip/_archived/2026.01.21_prof_firedet.cpp` and
    `src/methods/infer_proc/base_infer_proc.py` for details) to modify the
    inference results. Basically, if the confidence score of a detection is
    lower than `reliable_th`, we will set the detection to `None`, even though
    the detection is not `None` in the original inference results.
